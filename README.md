# Grove Light

A small browser platformer about a forest spirit carrying a light to a shrine. Leap the mist, bounce off beetles, and clear three short paths: First Light, Mossbridge, and Lantern Leap.

Open `index.html` in a browser. No build step.

**Controls**

- `A` / `D` move
- `Space` jump, then jump again in the air
- Land on beetles to knock them out
- On a phone, use the on-screen buttons

## An experiment with AI and Cursor

This was an experiment in building a finished game with AI inside [Cursor](https://cursor.com). The levels, movement, drawing, and screens were written in conversation with the editor rather than from a blank file by hand. The result is small enough to read in one sitting.
